# 周朝与春秋战国编年架构重构方案

理顺夏商周三代与东周列国争霸在历史学和时间轴交互上的重叠问题。将“西周（宗周镐京王制）”、“春秋（诸侯争霸中原）”、“战国（七雄变法兼并）”划分为平滑衔接的三段式编年主轴；春秋战国以诸侯霸主及七雄君王为主体，并清晰附注所尊周天子世系与纪年。

### User Review & Critical Decisions

> [!IMPORTANT]
> **已确认的架构决策**：
> - **编年与朝代主轴**：将原有重叠的宏观“周朝”解构为清晰的三段式顺承结构：
>   1. **西周**（前1046 — 前771）：镐京王制、武王克商、周公制礼作乐至幽王烽火戏诸侯。
>   2. **春秋**（前770 — 前476）：平王东迁洛邑，天子失威，齐桓公、晋文公、楚庄王、秦穆公、越王勾践等霸主迭兴。
>   3. **战国**（前475 — 前221）：三家分晋至始皇一统，魏文侯、秦孝公、秦昭襄王、赵武灵王、齐威王、燕昭王变法兼并。
> - **天子与诸侯纪年对应**：在春秋战国君王卡片与档案中，增加“周王室法统纪年”标注（如“周襄王赐伯”、“周威烈王初命为侯”、“周赧王五十九年灭周迁九鼎”），既突显春秋战国活跃的实际政治家，又保留大周八百年宗庙传承脉络。

## 1. 结构化历史方案梳理

### 历史重叠成因与优雅解法
- **重叠本质**：在历史编年体系中，“东周”（前770-前256）是朝代宗法概念，其前半段即“春秋”，后半段即“战国”（战国末期东周王室灭亡，前256-前221继续演进至秦统一）。若将“周朝”与“春秋、战国”并列在同一时间轴上，会导致公元前770年—前221年的历史时空被重复切分。
- **解构方案**：
  - 编年主轴序列改为：**夏朝 ➔ 商朝 ➔ 西周 ➔ 春秋 ➔ 战国 ➔ 秦朝 ➔ 西汉 ➔ 东汉 ➔ 三国 ➔ 两晋 ➔ 南北朝 ➔ 隋朝 ➔ 唐朝 ➔ 五代十国 ➔ 两宋 ➔ 元朝 ➔ 明朝 ➔ 清朝**。
  - 朝代罗盘与筛选：用户可一键直达“西周”、“春秋”、“战国”，再无时间重合与逻辑纠缠。
  - 世系图谱联动：
    - “西周世系”专精呈现文王、武王、成王、宣王、幽王之天子世系。
    - “春秋争霸谱系”呈现齐、晋、楚、秦、越霸主兴替与同盟。
    - “战国七雄变法谱系”呈现魏、秦、赵、齐、燕等七雄君臣变法图强脉络。
