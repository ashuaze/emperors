# 中华历代帝王长卷 (Chinese Imperial Chronology Scroll)

> 华夏帝胄全景图鉴 · 编年史长卷 · 宗法世系传承 · 五维能力风云对决

「中华历代帝王长卷」是一款兼具典雅古风与现代交互体验的中国通史帝王知识图鉴。系统完整收录从**夏、商、西周、春秋霸主、战国雄主**至**秦皇汉武、魏晋隋唐、宋元明清**的 **242 位华夏君主与帝王**，以宣纸朱砂古卷质感，重现五千年王朝兴衰与帝王风云。

---

## 🌟 核心特色功能

### 1. 全景编年时间轴与朝代速选罗盘
- **单行横向滑动罗盘**：支持从上古三代一路平滑滑向明清晚近，首行直观显示「朝代（收录帝王数）」，次行标注精准纪年区间；
- **详实帝王长卷**：详录庙号、谥号、姓名、年号、在位时期、重大历史功绩与转折事件，以及相伴的治世名臣良将；
- **全方位多维检索**：支持按姓名、庙号、年号、在位年代、名臣以及历史关键词极速检索。

### 2. 朝代世系图谱 (Lineage Trees)
- 还原各朝各代君位承继谱系；
- 清晰展现父子相承、兄终弟及、篡立交替与宗室分支脉络。

### 3. 五维帝王能力雷达与跨时空对决 (Imperial Duel)
- **五维历史能力模型**：
  - 🏛️ **政治手腕** (Political Acumen)
  - ⚔️ **军事统帅** (Military Command)
  - 🌾 **经济民生** (Economy & Livelihood)
  - 📜 **文化造诣** (Cultural Achievement)
  - ⚖️ **历史功过** (Historical Impact)
- **跨时空风云 PK**：支持任意挑选两位不同朝代的君主同台论道（如秦始皇 VS 汉武帝、唐太宗 VS 明成祖、汉光武帝 VS 宋太祖），自动生成对比雷达与对决评价。

### 4. 典雅古风视觉体系
- 采用宣纸暖底色调（`#FAF7F2`）与朱砂红（`#991B1B`）印章徽记；
- 融合古典衬线字体（Cinzel、Noto Serif SC、马山正毛笔字体）；
- 响应式布局，完美适配桌面宽屏、平板与手机端交互。

## 🚀 本地开发与构建

### 环境要求
- Node.js >= 18.0.0
- npm >= 9.0.0

### 本地启动
```bash
# 1. 克隆代码仓库
git clone https://github.com/<你的用户名>/<你的仓库名>.git
cd <你的仓库名>

# 2. 安装依赖
npm install --legacy-peer-deps

# 3. 启动本地开发服务
npm run dev
```
启动后在浏览器打开 `http://localhost:3000` 即可预览。

### 项目打包
```bash
npm run build
```
打包输出目录为 `dist/`，已预配置为相对路径 `./`，可在任意静态服务器或子目录部署。

## 🌐 部署至 GitHub Pages

本项目已配置自动化部署工作流（`.github/workflows/deploy.yml`）。

### 部署步骤：
1. **推送到 GitHub**：
   ```bash
   git init
   git add .
   git commit -m "feat: 中华历代帝王长卷首次发布"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/<你的仓库名>.git
   git push -u origin main
   ```
2. **启用 GitHub Pages**：
   - 打开 GitHub 仓库页面，点击 **Settings** -> **Pages**；
   - 在 **Build and deployment** 下将 **Source** 选为 **GitHub Actions**；
   - 系统将自动运行构建流水线，稍等 1-2 分钟即可在生成的域名（`https://<你的用户名>.github.io/<你的仓库名>/`）上访问。
